## _How To Read Systematically_ 
### 如何建立自己的阅读系统
***

#### 阅读是一种乐趣
原则：**只读感兴趣的内容**
- 前期：广泛涉猎，寻找兴趣
- 中期：将混沌博杂的书籍划分为不同的板块
- 后期：梳理逻辑线，组成阅读系统的枝干，并不断丰富枝干（加叶子）

#### 常见工具
- **Deepseek**：整理思维导图
- **微信读书**：阅读+做笔记
- **豆瓣**：找书，豆瓣评分参考性较强
- **github**：整理笔记
- **Z-Library**：图书资源
- **阅读器**：非必要，提升阅读体验，重度阅读力荐
